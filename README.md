# 🎱 BallsGames — 7 игр с шариками для тренировки ООП

Сборник из 7 классических и оригинальных игр, реализованных на C# с использованием Windows Forms. Проект создан для закрепления принципов объектно-ориентированного программирования: инкапсуляции, наследования и полиморфизма.

---

## 🏗 Архитектура

Проект разделён на несколько частей:

- **ClassLibrary** — общая бизнес-логика, модели шариков, физика движения

- **WinFormsApp** — графический интерфейс для каждой игры

## 🎮 Список игр

### 1. 🎯 Ловля шариков нажатием кнопки
Кнопка **"Создать"** генерирует множество шариков, которые движутся в случайных направлениях с разной скоростью.  
Кнопка **"Остановить"** фиксирует результат — сколько шариков **полностью находятся на форме**.

<img width="846" height="590" alt="шарики1" src="https://github.com/user-attachments/assets/12a9e98d-ebc3-46ac-9af1-5634a3626037" />

### 2. 🖱 Ловля шариков кликами мышки
Шарики движутся по форме. Игрок должен **кликать по ним мышкой**, чтобы "поймать". Счётчик пойманных шариков обновляется в реальном времени.  
Шарик считается пойманным, если он полностью находится на форме.

### 3. 🎱 Бильярдные шарики
Шарики появляются в случайных местах с разными скоростями. Реализовано **физическое отталкивание от стенок** — шарики упруго отражаются от границ формы.

### 4. 🧪 Давление газа
Экран разделён на две половины. В каждой — шарики **разного цвета**. При клике шарики начинают движение.  
Для каждой стенки подсчитывается **количество соударений** каждого цвета. При достижении полного перемешивания процесс останавливается

### 5. 🎆 Салют
При клике мыши из точки вылетают шарики в случайных направлениях и **падают вниз под действием силы тяжести**.  
Из нижней стенки вылетает один шарик, который в определённый момент **взрывается** на множество мелких.

<img width="791" height="467" alt="салют" src="https://github.com/user-attachments/assets/af9c350a-aa88-4859-ad4a-4686f34d4019" />

### 6. 🍉 Fruit Ninja
Из нижней границы вылетают шарики разного размера и падают под силой тяжести. Игрок **движением мыши** "режет" шарики, и они исчезают.

**Особенности:**
- 💣 **Бомба** — чёрный шарик. При касании игра завершается.
- 🍌 **Банан** — жёлтый шарик. При касании все шарики замедляются на некоторое время.

Классическая механика: игрок запускает снаряд из рогатки, чтобы сбить цели. Реализована простая физика полёта и столкновений.

- C# (.NET 6/8)

## 💡 Особенности реализации

- Общая физическая модель (скорость, ускорение, отскок)
- Разделение логики и UI
- Использование ООП: наследование, полиморфизм, инкапсуляция
- Обработка событий мыши

---

## 📐 Принципы ООП в проекте

- **Инкапсуляция** — каждый класс управляет своим состоянием
- **Наследование** — общий класс `Ball` расширяется для разных типов (`BombBall`, `BananaBall`, ...)
- **Полиморфизм** — разные реализации методов `Move()`, `Collide()`, `Draw()`
- **Абстракция** — интерфейсы для работы с хранилищем и физикой
